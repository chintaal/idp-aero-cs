# Arduino IDE Handoff

For teammates who use **Arduino IDE** instead of PlatformIO.

## What to send

Zip **one** folder:

| Profile | Folder to zip | When to use |
|---------|---------------|-------------|
| Tiny (start here) | `hardware/arduino/esp32_airbrake/` | First bring-up |
| Max | `hardware/arduino/esp32_airbrake_max/` | After tiny works; slower compile |

Each folder contains:

- `*.ino` sketch
- `cd_model.h` or `cd_model_max.h` (same folder)

No Python, no `airbrake/`, no PlatformIO required.

## One-time IDE setup

1. **File → Preferences → Additional boards manager URLs:**
   ```
   https://espressif.github.io/arduino-esp32/package_esp32_index.json
   ```
2. **Tools → Board → Boards Manager** → install **esp32** (Espressif).
3. **Sketch → Include Library → Manage Libraries** → install:
   - Adafruit BMP280 Library
   - Adafruit MPU6050
   - Adafruit Unified Sensor
   - Adafruit BusIO (if prompted)

## Board settings

| Setting | Value |
|---------|--------|
| Board | ESP32S3 Dev Module |
| USB CDC On Boot | Enabled |
| Upload Speed | 921600 (lower if upload fails) |
| Flash Size | 8 MB (match your board) |

## Upload

1. Open `esp32_airbrake.ino` (or `esp32_airbrake_max.ino`).
2. Select correct **Port**.
3. Click **Upload**.
4. **Tools → Serial Monitor** @ **115200**.

If upload fails: hold **BOOT**, tap **RESET**, release **BOOT**, upload again.

## Expected serial output

```
BMP280 OK
MPU6050 OK
Cd PINN loaded ...
--- PINN inference ---
```

Type `d50` to set 50 % deployment, `help` for commands.

## Updated model from ML team

Replace only the `.h` file in the sketch folder, then Upload again. Headers are regenerated by:

```bash
make train-cd        # tiny
make train-cd-max    # max
make sync-hardware   # copies into arduino/ folders
```
